# Recomendación de estudio

Para preparar el examen SAA-C03, prioriza estos grupos:

## Alta prioridad

- IAM
- Amazon VPC
- Amazon S3
- Amazon EC2
- Elastic Load Balancing
- Auto Scaling
- Amazon RDS
- Amazon Aurora
- Amazon DynamoDB
- AWS Lambda
- Amazon CloudFront
- Route 53
- AWS Organizations
- AWS KMS
- AWS WAF
- AWS Backup
- SQS, SNS y EventBridge

## Prioridad media

- ECS
- EKS
- Fargate
- Step Functions
- API Gateway
- ElastiCache
- Storage Gateway
- DataSync
- Direct Connect
- Transit Gateway
- Secrets Manager
- GuardDuty
- CloudWatch
- CloudTrail
- Config

## Prioridad complementaria

- Servicios de Machine Learning
- Servicios multimedia
- AWS Device Farm
- AWS Data Exchange
- Amazon Kendra
- Amazon Lex
- Amazon Polly
- Amazon Rekognition
