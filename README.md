# Guía de Estudio — AWS Solutions Architect Associate (SAA-C03)

Plan de preparación estructurado para aprobar el examen AWS Certified Solutions Architect – Associate (SAA-C03). Esta guía organiza los 4 dominios del examen en un cronograma de 14 semanas, con seguimiento de progreso, preguntas de práctica y recursos oficiales.

---

## Cronograma de 14 Semanas

| Semana | Dominio | Tarea | Tema Principal |
|--------|---------|-------|----------------|
| 1 | Dominio 1 — Seguridad | Tarea 1.1 | Acceso seguro (Módulos 1-5: Organizations, IAM, Identity Center, STS, Root/MFA) |
| 2 | Dominio 1 — Seguridad | Tarea 1.2 | Cargas de trabajo seguras (Módulos 6-9: VPC, WAF/Shield, Cognito/Secrets, Servicios de Seguridad) |
| 3 | Dominio 1 — Seguridad | Tarea 1.3 | Seguridad de datos (Módulos 10-14: KMS, ACM, Cifrado, Backups, Gobernanza) |
| 4 | Dominio 1 — Seguridad | Repaso | Repaso y práctica Dominio 1 |
| 5 | Dominio 2 — Resiliencia | Tarea 2.1 | Módulos 1-3 (Eventos, Microservicios, Contenedores) |
| 6 | Dominio 2 — Resiliencia | Tarea 2.1 | Módulos 4-5 (Serverless, Balanceo de Carga) |
| 7 | Dominio 2 — Resiliencia | Tarea 2.1/2.2 | Módulos 6-8 (Caché, Almacenamiento, Alta Disponibilidad) |
| 8 | Dominio 2 — Resiliencia | Tarea 2.2 | Módulos 9-11 (DR, Observabilidad, Servicios Administrados) |
| 9 | Dominio 3 — Alto Rendimiento | Tareas 3.1-3.2 | Módulos 1-2 (Almacenamiento + Computación) |
| 10 | Dominio 3 — Alto Rendimiento | Tareas 3.3-3.4 | Módulos 3-4 (Bases de Datos + Redes) |
| 11 | Dominio 3 — Alto Rendimiento | Tarea 3.5 | Módulo 5 (Analítica e Ingesta) |
| 12 | Dominio 4 — Costos | Tareas 4.1-4.2 | Módulos 1-2 (Almacenamiento + Computación Optimizados) |
| 13 | Dominio 4 — Costos | Tarea 4.3 | Módulo 3 (Bases de Datos) |
| 14 | Dominio 4 — Costos | Tarea 4.4 | Módulo 4 + Herramientas de Costos (Redes + Cost Explorer/Budgets) |

## Pesos del Examen

Distribución oficial de preguntas por dominio en el examen SAA-C03:

| Dominio | Peso |
|---------|------|
| Dominio 1 — Diseño de Arquitecturas Seguras | 30% |
| Dominio 2 — Diseño de Arquitecturas Resistentes | 26% |
| Dominio 3 — Diseño de Arquitecturas de Alto Rendimiento | 24% |
| Dominio 4 — Diseño de Arquitecturas con Optimización de Costos | 20% |
| **Total** | **100%** |

## Cómo Usar esta Guía

1. Cada documento de dominio incluye checkboxes (`- [ ]`) junto a módulos y laboratorios para registrar tu avance.
2. Cuando completes un módulo o laboratorio, cambia `- [ ]` por `- [x]` en el archivo correspondiente.
3. Actualiza la tabla de **Progreso General** en este README para reflejar tu avance global.
4. Usa la sección **Notas Personales** al final de cada documento de dominio para anotar conceptos clave, áreas débiles y trucos para el examen.
5. Resuelve las preguntas de práctica de cada dominio al terminar sus semanas asignadas para medir tu nivel de preparación.
